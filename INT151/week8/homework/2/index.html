ข้อ 2: ปุ่มอ่านเพิ่มเติม / ย่อ (classList.toggle)

โจทย์ (Instructions)

  • มี <button id="toggle-btn">อ่านเพิ่มเติม</button> และ <p id="detail" class="hidden">...</p>
  • CSS ซ่อน element ที่มีคลาส .hidden ไว้ล่วงหน้า
  • เขียนโค้ดผูก click event ที่ปุ่ม ให้สลับ (toggle) คลาส hidden ของ <p> ทุกครั้งที่กด

พรีวิวการทำงาน (Live Preview)

รายละเอียดสินค้า: เสื้อยืดคอกลม ผ้าฝ้าย 100% มีให้เลือก 5 สี

เฉลยโค้ด (Solution Code)

// ผูก element
const toggleBtn = document.querySelector('#toggle-btn');
const detail = document.querySelector('#detail');

// Event Listener สำหรับสลับการแสดงผล
toggleBtn.addEventListener('click', () => {
  detail.classList.toggle('hidden');
});
